    Agentic Research Framework (ARF)

    Welcome to the Agentic Research Framework (ARF) documentation. ARF is a production-grade, open-source research accelerator engineered for autonomous AI coding agents (Google Antigravity, Claude Code, Cursor, OpenAI Codex, Gemini CLI) and human research engineers.

    Why ARF?

    Autonomous AI coding agents can dramatically accelerate scientific discovery—drafting implementations, exploring hyperparameter regimes, isolating edge-case bugs, and synchronizing experimental outcomes with paper manuscripts. However, without strict architectural boundaries, autonomous agents frequently hallucinate baseline comparisons, leak test data into feature preprocessors, hardcode non-existent evaluation metrics into LaTeX, or introduce non-deterministic results.

    ARF solves this by providing: - 🛡️ Canonical Multi-Agent Contracts: Universal behavior contracts in AGENTS.md and dedicated adapters for Claude, Gemini, Cursor, and Antigravity. - 🔬 Strict Research Integrity: Zero-fabrication enforcement where all LaTeX tables and text macros originate from frozen JSON result registries (numbers.tex). - 🤖 Multi-Subagent Deep Dive Protocol: Built-in prompts for deep-dive codebase exploration, specialized prompt synthesis, and bounded self-improvement loops. - 📦 Fully-Typed Starter Codebase: A clean PEP 561 Python package (agentic_research), CLI entrypoints (arf), and out-of-the-box unit test suites. - 🔒 Zero-Egress Security: Local-first defaults, air-gapped data boundaries, and strict exclusion of raw datasets and unpublished manuscript drafts.
