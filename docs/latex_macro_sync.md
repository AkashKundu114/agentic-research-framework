# Single-Source of Truth: LaTeX Macro Synchronization

One of the most pervasive failure modes in AI-assisted scientific writing is **numerical hallucination**: an agent writes believable-looking baseline results, table cells, or p-values directly into LaTeX prose that do not match the experimental code.

The **Agentic Research Framework (ARF)** eliminates this issue using a **Single Source of Truth (SSOT)** architecture.

---

## 1. The Architecture

```mermaid
flowchart LR
    A["Experimental Run<br>(scripts/run_experiment.py)"] -->|Write Metrics| B["Frozen Results Registry<br>(results/results.json)"]
    B -->|Parse & Format| C["Macro Sync Script<br>(scripts/generate_tables.py)"]
    C -->|Generate Macros| D["LaTeX Macro File<br>(paper/numbers.tex)"]
    D -->|Include via \input{}| E["Manuscript<br>(paper/main.tex)"]
```

---

## 2. Defining Macros in `paper/numbers.tex`

Instead of writing hardcoded numbers in LaTeX:
```latex
% AVOID THIS (Error-prone and unverifiable):
Our proposed method achieved an accuracy of 84.7% on the benchmark.
```

Define semantic LaTeX macros generated from frozen JSON artifacts:
```latex
% RECOMMENDED (Single source of truth):
\newcommand{\BaselineAccuracy}{84.71\%}
\newcommand{\BaselineStabilityIndex}{0.6121}
\newcommand{\ProposedMethodRuntimeSec}{4.12\,\text{s}}
```

In your manuscript (`paper/main.tex`):
```latex
\input{numbers.tex}

Our proposed method achieved an accuracy of \BaselineAccuracy{} 
with a stability index of \BaselineStabilityIndex{}.
```

## 3. Automated Macro Generator Script

ARF provides [`scripts/generate_tables.py`](../scripts/generate_tables.py) as an extensible template for parsing `results/*.json` and producing both LaTeX macros and publication tables:

```python
import json
from pathlib import Path

def sync_numbers_to_latex(results_path: Path, output_macro_path: Path) -> None:
    data = json.loads(results_path.read_text(encoding="utf-8"))
    metrics = data.get("metrics", {})

    lines = [
        "% Auto-generated by scripts/generate_tables.py. DO NOT EDIT DIRECTLY.",
        f"\\newcommand{{\\BenchmarkAccuracy}}{{{metrics.get('accuracy', 0.0) * 100:.2f}\\%}}",
        f"\\newcommand{{\\StabilityIndex}}{{{metrics.get('stability_index', 0.0):.4f}}}",
    ]
    output_macro_path.write_text("\n".join(lines) + "\n", encoding="utf-8")
```

## 4. Automated Sanity Check in CI

To enforce that no paper claims deviate from experimental logs, the CI test suite includes automated assertion checks:

```python
def test_paper_macros_match_results():
    results = json.loads(Path("results/metrics.json").read_text())
    macros = Path("paper/numbers.tex").read_text()
    
    expected_acc = f"{results['metrics']['accuracy'] * 100:.2f}\\%"
    assert expected_acc in macros, "LaTeX numbers.tex is out of sync with results!"
```
